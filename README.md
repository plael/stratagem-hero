# stratagem-hero

슈퍼 구축함 자유의 날개 디스코드 서버의 함교 오락기, **스트라타젬 히어로**입니다.

- 디스코드 액티비티(게임 창)로 열리는 한 장짜리 웹 게임 (`index.html`)
- W A S D / 방향키로 스트라타젬 코드 입력, 휴대폰은 화면 십자 버튼
- 코드를 끝까지 맞혀야 스트라타젬이 내려와 다가오는 적을 처리
  - 궤도·이글: 그 공격으로 / 지원 무기: 헬포드로 받아서 사격 / 그 밖: 헬포드로 찍어 누름
- 게임이 끝나면 나오는 기록 코드를 오락기 채널의 **🏆 기록 올리기**에 넣으면 순위표에 올라감
